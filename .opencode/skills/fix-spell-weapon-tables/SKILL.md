# Починка таблиц атаки психосил

## Источник истины
Таблица генерируется **только** из `weaponProfile` в JSON. Текст `description`
в JSON и текст в .md не влияют на содержимое таблицы.

## Формат таблицы
```
| Rng | RoF | Dmg | Pen | Свойства |
|-----|-----|-----|-----|----------|
| {range} | {rofSingle}\{rofShort}\{rofLong} | {damage} {damageType} | {pen} | {properties через ", "} |
```
- Пустое/`-`/`—` в RoF → `–` (en-dash), части соединяются `\`. Пример: `S\–\–`
- `pen` пустой/`0` → `0`
- `properties` пустой список → `–`

## Шаг 1: отчёт
```
uv run python .opencode/skills/fix-spell-weapon-tables/scripts/find_gaps.py data/core_rules/merged.json > /tmp/gaps_report.yaml
```
Отчёт группирует по файлу вики только записи с расхождением. Категории:
- `missing` — таблицы нет
- `outdated` — таблица есть, но не совпадает с ожидаемой (например, отсутствует RoF)
- `embedded_raw_stats` — сырой профиль оружия залит текстом прямо в `**Эффект:**` (паттерн вида `Rng Dmg Pen Свойства`)
- `block_not_started` — заголовок психосилы не найден в целевом файле вообще (перенос ещё не сделан или имя не совпадает — разобрать отдельно, не чинить таблицей)

## Шаг 2: правка (файл за файлом)
Для каждой записи из отчёта, кроме `block_not_found`:

1. `view` актуального блока `###### {nameEn} / {name}` в целевом .md.
2. `missing` / `outdated`: вставить `expected_table` из отчёта сразу после
   последнего предложения `**Эффект:** ...`, отделив пустой строкой сверху
   и снизу. Если после `**Эффект:**` уже была таблица — заменить её целиком
   на `expected_table`, остальной текст (хвостовая проза после таблицы,
   если есть) не трогать.
3. `embedded_raw_stats`: сначала убрать из текста `**Эффект:**` сырой
   дублирующий фрагмент профиля оружия (обычно вида `Rng Dmg Pen Свойства\n...`
   слитным текстом без markdown-таблицы), затем вставить `expected_table`
   на его место. Остальной текст описания сохранить дословно.
4. Использовать `str_replace` с точным `old_str` из `view`, не переписывать
   блок целиком.
5. Не трогать записи со статусом `ok` (их нет в отчёте) и `block_not_found`.

## Что не делать
- Не адаптировать/сокращать `description`.
- Не менять таблицу вручную по вкусу — только по данным `weaponProfile`.
- Не коммитить — правки остаются в рабочем дереве.
